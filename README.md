<div align="center">

A clean product-listing interface built with semantic HTML and CSS, featuring a multi-column card grid and subtle hover interactions.

## ✨ What this project demonstrates

- Product cards arranged in a four-column CSS Grid layout.
- Product image areas with consistent sizing and cropping.
- Product information panels with clear visual hierarchy.
- Hover elevation and shadow transitions.
- Font Awesome icons for shopping-related UI details.
- A centered content container with reusable spacing.

## 🧰 Built with

| Tool | Use |
| --- | --- |
| HTML5 | Page structure and product content |
| CSS3 | Grid layout, card styling, spacing, and hover effects |
| Font Awesome 6.5 | Shopping and interface icons |
| Poppins font stack | Product-focused typography |

## ▶️ Run locally

~~~bash
git clone https://github.com/modewika1-star/t7.git
cd t7
~~~

Open `index.html` in your browser. No package installation or build step is required.

## 📁 Main files

- `index.html`: product grid and page styles.
- Product image assets are referenced by the HTML.
